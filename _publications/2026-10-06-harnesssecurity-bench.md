We study how coding agent harnesses protect tool execution and balance security with task utility. **HarnessSecurity** examines 40 harnesses and organizes their controls into ten security mechanisms.

**HarnessSecurity-Bench** provides 23 tasks across five attack surfaces, with separate checks for legitimate task completion and attack effects. We evaluate nine mechanisms across six harnesses in 2,500 trials.

The results show that security controls have different effects on protection and utility, and that alternative execution paths can bypass restrictions. The benchmark supports evaluating these tradeoffs under controlled security settings.
